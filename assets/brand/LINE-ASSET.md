Use only to identify the actual LINE contact channel. Do not recolor, distort,
crop, animate, or imply endorsement. The shared mark reserves 25% clear space
on each side; rendered height is 28px on desktop and at least 40px on mobile.
The floating launcher is 40px on all screen sizes.

The old `line-icon.svg` remains only for historical exports. CMS migration v17
replaces that exact bundled value in contact/footer slots, preserving custom
uploads and intentional blanks. Exported historical posters are not migrated.
